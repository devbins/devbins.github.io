Mac 上体验 Omarchy 发行版

2026-09-15
Linux
559 words 2 mins read

Contents

  • 前言
  • 介绍
  • 使用
  • 总结

前言

一直想在 Apple silicon 的 Mac 上体验桌面版的 Linux，苦于没有合适的，像喜欢的 Arch 系就没有，要自己折腾。

Ubuntu 好像是有一个 arm 的桌面版，但是我比较喜欢 Arch。

直到最近我看到一个叫 Omarchy 的发行版，界面非常好看，基于 Hyperland 的平铺式桌面，于是我就好奇的去了解了一下。

介绍

Omarchy 的作者和 Ruby on Rails 的作者是同一个，都是 David Heinemeier Hansson(DHH)。

Omarchy 是基于 Arch 并且桌面环境使用的是 Hyperland 平铺式的环境，开箱即用。

Omarchy 还有一个特点是自带智能体，智能体在 Omarchy 中是一等公民。

它对硬件要求也极低，哪怕是一台 2011 年、只有 2GB 内存的老 ThinkPad X220，跑起 Omarchy 都绰绰有余。

使用

想要用上 Omarchy 非常简单，通常我们会在虚拟机中先体验，这一点 Omarchy 也考虑到了直接做了个 app，都不用安装虚拟机软件。

由于下载较慢，我把下载好的文件传到网盘了，方便需要的方便需要的小伙伴，地址在文末。

下载好后直接安装就能用。

如果没有使用过平铺桌面一开始会比较懵，介绍三个我认为比较重要的操作

  1. 打开终端 快捷键是 Super(CMD) + 回车
  2. 打开 Omarchy 菜单 快捷键是 Super(CMD) + 空格，这里可以数据要打开应用的名字会直接过滤出来
  3. 查看快捷键的快捷键 Super + K 上面这两个也可以通过这个来查看

剩下的就自己慢慢摸索了，这样才有意思。

总结

文件比较大，下载挺慢的，我下载存到网盘了，方便需要的小伙伴，地址是：https://pan.quark.cn/s/bca8874e0a3b 里面的 TryOmarchy.dmg 就是
